账号审阅自动化工具（Windows演示版）
====================================

一、电脑要求

1. Windows 10或Windows 11，64位。
2. 安装64位Miniconda或Anaconda。
3. 安装脚本会自动创建独立的Python 3.12 Conda环境，无需另外配置Python。
4. 首次创建环境和安装依赖时需要访问Conda及Python软件源；
   正式处理审阅文件时不需要访问外网。

二、首次安装

1. 将整个文件夹解压到本地磁盘，路径尽量不要过长。
2. 双击“01_install.bat”。
3. 等待出现“Installation completed”。
4. 安装只需执行一次。

脚本将在当前工具目录创建“.conda_env”，并自动安装requirements.txt中的依赖。
如果公司电脑不能访问外网，请由IT人员配置Conda/pip镜像或离线安装依赖。

三、启动工具

1. 双击“02_start.bat”。
2. 请保持命令窗口开启。
3. 浏览器会自动打开：http://127.0.0.1:5050
4. 上传审阅Excel和Supporting ZIP，等待执行完成后下载结果。
5. 使用结束后，在命令窗口按Ctrl+C停止工具。

四、数据安全说明

1. 工具仅监听127.0.0.1，其他局域网电脑不能直接访问。
2. Excel、ZIP、截图和OCR均在当前电脑本地处理。
3. 工具运行过程不调用外部OCR或OpenAI接口。
4. 本发布包不包含测试数据、客户数据、历史上传文件或历史输出结果。
5. 请勿将处理后的业务文件与程序安装包一起再次转发。

五、常见问题

1. 提示“Conda was not found”
   请安装64位Miniconda或Anaconda，然后重新运行“01_install.bat”。

2. 创建环境或安装依赖失败
   检查Conda、网络、公司代理和软件源；受限环境请联系IT进行离线安装。

3. 浏览器没有自动打开
   手工访问：http://127.0.0.1:5050

4. 页面无法访问
   检查“02_start.bat”窗口是否仍在运行，以及是否显示错误信息。
